# BinnenBeter

Mobiele webapp die de voorwaarden van de gemeentelijke parkeergarages, wijkstallingsgarages en fietsenstallingen van Rotterdam in gewone taal (B1) uitlegt, voor collega's in de uitvoering.

Prototype van team Makers, afdeling Parkeren. Geen officiële website van de gemeente. Bij twijfel geldt altijd de originele tekst van de voorwaarden op rotterdam.nl.

Bronnen:
- Algemene Voorwaarden 2024 parkeervoorzieningen: https://www.rotterdam.nl/media/3759
- Algemene voorwaarden fietsparkeren: https://www.rotterdam.nl/algemene-voorwaarden-fietsparkeren
- Abonnement parkeergarage of parkeerterrein: https://www.rotterdam.nl/abonnement-parkeergarage-of-parkeerterrein-aanvragen

Illustraties gemaakt met ChatGPT. Eén statisch bestand (`index.html`) plus `img/`, gehost via GitHub Pages.
